# Foundation

Engine objects, scene execution and resource foundations.

The built-in Async, Attributes, BuildCore, Collections, Instrumentation, Math and Serialization modules provide frame-driven tasks, metadata, build target descriptors, data containers, diagnostic hooks, deterministic value types and serialization contracts. Base host services come from the platform host. YAML, JSON and XML formats are in Serialization.

Foundation is a built-in Core module and is available in every engine installation.
