# 编辑器资源制作契约

Prefab 的 Variant、嵌套引用、覆盖项窗口和 Apply/Revert 流程见 [Prefab 制作](PrefabAuthoring.md)。

## 制作工具与扩展

Core 提供 Inspector、Undo、资源数据库、窗口、节点和轨道等扩展接口。具体资产制作工具由启用的扩展提供，不由 Core 注册或依赖。通过 Package Manager 打开当前版本扩展的文档与示例。

双击资源由已注册的资源打开处理器分派。制作工具应将资产修改纳入 Undo，通过正常保存流程写入 Assets；进入 Play、关闭窗口或停止预览时，恢复临时采样的场景属性。保存和撤销前先还原预览，以保留用户对其他属性的编辑。

## 引用与生命周期

资源成员使用 BObject 对象引用，序列化保留稳定 GUID 和 SubAsset 的 localIdentifier。旧路径字段仅用于数据迁移；兼容属性不应再次序列化为平行状态。

显式销毁 BAsset 会注销对象、清除缓存引用并释放自身拥有的资源。共享资源不连带销毁；预览资源由创建它们的工具释放。已销毁对象不得再次从资源缓存返回；运行时资源禁止保存回工程。

Play 镜像保留内部资源的隔离副本，副本间共享同一映射后的资源。停止 Play、创建失败、热重载回滚或成功替换时释放对应副本。自定义 BAsset 若包含未序列化的内部数据，可重写 CaptureClonePayload / RestoreClonePayload；传输数据使用 CLR 或引擎本体类型，内部 BObject 引用通过 cloneObject 映射，以支持程序集更新后的同名类型。

Core 不实现具体扩展的预览、解码或绘制。扩展拥有对应数据的克隆、恢复和释放行为；其注册必须随所属程序集卸载而清理。
