# Prefab provenance and source-service boundaries

Core Runtime owns live source identity, instance boundaries and the operation that connects an already resolved asset to an existing hierarchy. `PrefabAssetOperations.GetSourceIdentity`, `IsInstanceRoot` and `GetInstanceReference` expose values, never mutable source documents, maps or private setters. The reference query examines only the specified object; ancestor selection and address resolution remain editor policy. These queries require no registered source provider, Editor or graphics implementation and introduce no cache, scan, subscription or allocation.

The existing `ConnectHierarchy(GameObject, PrefabAsset)` operation is public. It rejects null or destroyed inputs before changing borrowed state and retains live objects and their IDs. Source resolution still uses the existing Core prefab mechanisms and registered resolver. This does not duplicate file loading or variant merging in Core.

EditorServices retains PrefabUtility's save/import ordering, path restrictions, Selection, Undo, dirty state, notifications and nearest/outermost traversal. It obtains `IPrefabDocumentCodec` and `IPrefabAuthoringBackend` through the existing assembly-owned service registry. AssetPipeline continues to provide file persistence and variant policy. The editor facade does not reach through Core's private wrappers or prefab metadata, and does not acquire a concrete AssetPipeline dependency.

Run `Test-PrefabProvenanceContracts.ps1` with the installed consumer binary closure and an output directory under the workspace Temp directory. The Core consumer has no Core Editor/package reference or friendship; it verifies nested same-asset boundaries, cloning, detached contents, connection validation, partial/full unpack and allocation-free repeated queries. The workflow consumer exercises real source documents and services, including hostless and indexed save/connect, GUID reconciliation, variants, provider replacement/removal, failure handling and existing editor policy. Its proxy simulates only import/catalog bookkeeping; recording adapters delegate actual document/variant work to the registered implementation. Existing Prefab editing and authoring tests continue to cover Undo, refresh and value reconciliation.

Partial unpack now stops at an independently referenced nested instance, including one that uses the same asset as its parent. Previously matching only the asset ID cleared that nested instance's source IDs while leaving its reference record behind. Complete unpack still clears the entire hierarchy. This uses the stored instance boundary, not package knowledge or source-file policy.

This change preserves serialized data and package dependency declarations. It does not certify all other private accesses or the complete package architecture.
