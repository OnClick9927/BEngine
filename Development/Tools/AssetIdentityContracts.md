# Asset identity and managed document ownership

Core owns managed object graph capture/restore and private engine identity fields. `ManagedAssetSerialization.Serialize(BObject)` and `DeserializeObject(string)` expose the existing native document representation without exposing its mutable DTO. Existing typed asset APIs remain available. The version-one and version-two wire formats are unchanged; serialized type resolution uses the active runtime type index.

Core Editor owns `EditorAssetBinding.BindImported` and `BindEmbedded`. Imported binding validates metadata before committing the object GUID and asset origin; Prefab binding keeps the document identity consistent. Embedded binding validates a main owner, object GUID and positive local identifier, and preserves existing physical origins. The caller owns the object; these operations do not open files, construct caches, emit import notifications, or record Undo.

`IManagedAssetDocumentCodec` is a neutral source persistence extension, alongside the existing scene and Prefab codecs. AssetPipeline registers its implementation, reads through the platform file service, and uses its existing atomic source replacement and failure cleanup. It retains no additional per-frame work or object cache. Assembly-owned default registrations are removed on unload.

EditorServices keeps the AssetDatabase facade, weak caches, file selection, import requests, embedded metadata containers, write protection and dirty-state policy. It uses the registered codecs for native source persistence and the public identity contracts for imported and embedded objects. It reuses `RuntimeAssetReferences` for sub-asset identity queries and address changes. It no longer accesses private managed document DTOs, Prefab document IDs, `BObject.Id` setters or BAsset's internal binding members from AssetDatabase. The built-in scene loader also uses the public codec and scene-path binding contracts.

This phase does not claim the whole import system or all package boundaries are finished. AssetDatabase still selects source formats and handles metadata policy; remaining provenance, reflection, public signatures and manual friendship require further audit.

Run `Test-AssetIdentityContracts.ps1 -EngineBinaries <consumer closure> -OutputDirectory <Temp directory>`. The Core probe references no package assembly. The workflow probe uses real native source codecs and filesystem operations; its fixture host only supplies deterministic imported-record queries and import bookkeeping. It covers GUID and local-identifier stability, managed graphs and legacy documents, cache invalidation, Prefab/scene loading, embedded and file-backed sub-assets, atomic replacement failure, fallback representations and provider unload. Existing editor-authoring fixtures explicitly install the source provider, retaining their no-workbench/no-GPU assertions.
