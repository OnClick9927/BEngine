开始之前

准备创作环境

当前已验证的开发流程以 Windows 桌面为起点。Hub 会检测并复用已有的兼容环境。

  • Windows 10 / 11，x64
  • .NET 10 Windows Desktop Runtime，供 Hub 与编辑器使用
  • .NET 10 SDK，用于脚本编译和游戏构建
  • 支持 Vulkan 或 OpenGL 的图形环境
  • 联网下载引擎、扩展包及更新

开始之前，你可能想知道。

可以免费使用和用于商业项目吗？

引擎采用 MIT 许可证，允许使用、修改和分发，包括商业使用。请保留版权和许可声明；第三方组件遵循各自许可。

需要安装所有扩展包吗？

不需要。Core 提供基础能力，你可以按项目需要启用扩展包，并通过 Package Manager 管理依赖。

详细文档在哪里？

从 Hub 的「引擎与包」选择对应版本，使用文档入口打开本地手册。官网只保留基础介绍。

目前支持哪些平台？

Windows 编辑器与 Player 已验证。Linux/macOS 仍需对应系统验证；Android、iOS 和 Web 的完整 Player 仍在开发中。
