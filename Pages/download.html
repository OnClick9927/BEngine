BEFORE YOU START

准备创作环境

当前已验证的开发与运行流程以 Windows 桌面为起点。首次缺少运行库时，启动提示会引导下载；已有兼容环境可直接使用。

  • Windows 10 / 11
  • x64 .NET 10 Windows Desktop Runtime，供 Hub 与编辑器共享
  • .NET 10 SDK，用于项目脚本编译与游戏构建；Hub 会检测并复用已有兼容环境
  • 支持 Vulkan 或 OpenGL 的图形环境
  • 联网下载引擎、扩展包及后续更新

A FEW GOOD QUESTIONS

开始之前，你可能想知道。

BEngine 可以免费使用和用于商业项目吗？

引擎采用 MIT 许可证，允许使用、修改和分发，也允许商业使用。请遵循许可证并保留版权与许可声明。完整条款见 MIT License ↗。

有 Unity 开发经验，入门方式有什么相似之处？

BEngine 使用 C#，采用 Scene、GameObject、Component 和 MonoBehaviour 等工作流，并提供 Hierarchy、Inspector 和 Play 模式。具体 API 与资产格式以 BEngine 文档为准，现有 Unity 项目需要适配。

现在可以发布到哪些平台？

Windows 编辑器与 Player 流程已验证。Linux / macOS 已有桌面适配，仍需对应系统验证。Android、iOS 和 Web 的完整原生宿主仍在开发中，当前不提供完整可用的移动端或 Web Player。请查看 平台状态 ↗。

官网的 39 个扩展包都需要安装吗？

不需要。Core 提供基础场景和资源能力，你可以按项目需要启用扩展包，并通过 Package Manager 管理依赖。在 Hub 选定引擎版本后，可以查看该版本兼容的包。

在哪里找到示例或反馈问题？

包文档和 Examples 提供可导入场景，可先在 示例展示 ↗ 了解项目与运行方式。遇到问题时，请参考 问题反馈指南 ↗，准备版本、复现步骤与相关日志。
