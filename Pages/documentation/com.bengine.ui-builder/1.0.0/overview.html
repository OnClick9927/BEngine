UIBuilder

Visual authoring, previews and samples for UIElements documents.

Enable com.bengine.ui-builder in Package Manager. Disabling the package removes its tools and types from the project.

自定义控件

Library 的 Standard 页显示内置控件，Project 页显示 UxmlFactoryRegistry 注册的工程/扩展包控件。注册时可以用 UxmlFactoryOptions 配置名称、分类和默认属性；双击插入后可撤销/重做、保存 UXML。注册/注销以及程序集卸载会自动更新列表。
