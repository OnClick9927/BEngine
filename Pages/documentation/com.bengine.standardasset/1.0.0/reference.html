StandardAsset

仅依赖 BEngine Core 的可编辑起步组件包。

在 Package Manager 点击 Import，包会复制到工程的 Assets 目录 Assets/3rd/StandardAsset。 源码通过 StandardAsset.asmdef.yaml 编译，重新打开工程会保留你的修改。

  • TopDownMover：WASD / 方向键，或外部 moveInput。
  • CameraFollow：平滑跟随、偏移和立即定位。
  • Rotator：持续旋转。
  • Bobbing：正弦浮动。

打开示例工程，在主菜单选择 StandardAsset；组件也可通过 Add Component → Standard Asset 添加。
