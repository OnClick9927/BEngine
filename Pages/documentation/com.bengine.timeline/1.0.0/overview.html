Timeline

com.bengine.timeline 提供 TimelineAsset、PlayableDirector、轨道、片段、信号、媒体编排和 Timeline 编辑器窗口。运行时代码位于 BEngine.Timeline，编辑器代码位于 BEngine.Timeline.Editor；命名空间保持 BEngine 和 BEngine.Editor。

Timeline 的动画轨道依赖 com.bengine.animation，音视频适配依赖 com.bengine.audio、com.bengine.video。Animation 与 Animator 共用 Animation 包，安装 Animation 不需要安装 Timeline。

双击 .timeline.yaml 打开窗口。运行时选中带有 PlayableDirector 的对象，如果它的资产与窗口一致，窗口跟踪该实例的时间与播放状态。Core 仅提供 TrackEditorCanvas、节点画布、资源和生命周期接入点。

通过 Add Track 创建 Control 轨道，将 Binding 指向含有子 PlayableDirector 的对象。片段可指定 Nested Timeline 覆盖资源；留空时使用子 Director 原有资源。Clip In、Speed 和 Loop Nested Timeline 控制局部时间。Control Activation 决定是否随片段开关目标对象。支持多层嵌套，父级先调度，受控子级不会自行再次推进。停止、解绑或离开片段时恢复子级此前的资源、时间和播放状态。

Camera 轨道的 Binding 指向输出 Camera2D 所在对象，每个片段的 Shot Camera 指定镜头来源。来源相机可以禁用，避免额外渲染。片段重叠时混合位置、最短方向旋转、Size 和背景色；视口和剔除设置采用权重最大的来源。Blend In/Out 可调整过渡。跳回、空档和停止会恢复正确的镜头状态。复制片段会创建独立的镜头绑定，剪切和编辑支持 Undo/Redo。

Director 的负 Speed 反向播放，Play 从末尾开始；wrapLoop 支持正反向循环。信号沿经过的时间区间发送，包含嵌套和整段跨越的片段；暂停或手动 Evaluate/拖动时间不会触发信号。Control 重叠时起点较后的片段控制目标。循环控制绑定、超过 64 层嵌套，以及多个父级同时控制同一子 Director 会报错。

Timeline 文档 v2 保存控制和镜头设置，仍可加载 v1。嵌套资源须先保存，再保存父资源。场景保存 Director 的对象绑定。Play 模式禁止编辑资源和镜头绑定。验证工程为 Temp/Validation/TimelineEnhancements，包含编辑器操作、持久化、嵌套调度/信号、反向播放及 Vulkan/OpenGL 像素读回；独立 Player 的验收状态见 Temp/Validation/Reports/EngineCompletionChecklist.md。

Timeline 自己提供 AudioSource、VideoPlayer 适配器，通过组件已有的播放 API 控制隐藏的临时播放器。暂停时保留当前采样状态，停止或解绑时恢复原组件状态。Audio、Video 不引用 Timeline，也不包含 Timeline 接口或专用字段。

扩展既有组件时，在消费方包实现 Timeline 的 ITimelineMediaAdapter，返回 ITimelineMediaPlayable 播放会话。为 Timeline 专门编写的组件也可以直接实现 ITimelineMediaPlayable。不需要修改被适配组件。
