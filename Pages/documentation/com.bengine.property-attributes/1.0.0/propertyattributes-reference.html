PBEngine Property Attributescom.bengine.property-attributes

运行、分包与验证

属性继承 ExtendedPropertyAttribute，由一个 useForChildren 的 PropertyDrawer 组合处理。ShowIf/HideIf 决定可见性，EnableIf/DisableIf/ReadOnly 决定可编辑性。Required/ValidateInput 提示计入 GetPropertyHeight；Prefix/Suffix/HorizontalLine 和 EnumFlags 实际参与绘制。InlineButton 通过 Undo.RecordObject 记录动作。

快速开始

  1. 创建可序列化 MonoBehaviour 字段或属性，先使用 Range 与 Required，在 Inspector 确认 SerializedProperty 能找到成员。
  2. 为 ShowIf 或 ValidateInput 指定对象上真实存在的条件成员/方法；分别验证条件通过与失败时的布局。
  3. 逐步组合 Title、InfoBox、Prefix/Suffix、InlineButton，调整 order；窄 Inspector 中确认输入框和提示不重叠。

ExtendedPropertyAttribute, ExtendedPropertyDrawer, ShowIf, Required, ValidateInput, EnumFlags, Prefix, Suffix, HorizontalLine, InlineButton

扩展与平台接口

运行时使用 Fix64 和主线程 BTask；通过平台服务读写资源，不直接创建主机文件或网络连接。编辑器代码放在 Editor 装配，停止场景时取消请求并解除订阅。

资源分包与更新

AssetImporter.assetBundleName/assetBundleVariant 指定资源组；BuildPipeline.BuildAssetBundles 接受导入设置或 AssetBundleBuild[]。跨包引用记录为目录依赖。RequiredBundleNames 控制首次安装，IAssetBundleDownloadManager 下载可选组和依赖。已安装可选包参与之后的版本更新。

行为边界

这是 BEngine IMGUI PropertyDrawer 扩展，不是完整 Odin Inspector。条件和验证方法应快速且无副作用，因为布局和重绘都可能求值。运行时代码不能引用 Editor 装配；自定义 drawer 放在 Editor 目录和编辑器 asmdef 中。不同属性的约束需要保持上下界一致。

排查与验证

  • 字段消失：检查 ShowIf 条件名和返回值；不存在的条件会判为 false。
  • 提示盖住下一项：使用 EditorGUI.GetPropertyHeight 分配 Rect，不能固定写死单行高度。
  • 编辑后无法撤销：通过 SerializedProperty 写入并 ApplyModifiedProperties；直接修改目标前调用 Undo.RecordObject。
  • 切换条件使错误提示出现/消失，验证高度与实际绘制行数一致。
  • 在绘制失败或结束后确认 GUI.enabled 和 EditorGUI.indentLevel 恢复，避免污染后续字段。
  • 用 Flags 枚举选择多个位，再撤销；InlineButton 修改字段后撤销并确认场景 dirty 状态。

Package Manager 导入示例：AttributesGallery、InspectorAttributesAndDrawer。在 Project 打开场景，检查 Hierarchy/Inspector，比较 Scene 与 Game，Play 后查看 Console，Stop 后再次运行。

组件字段组合代码

using System.Collections.Generic;
using BEngine;
using BEngine;

[AddComponentMenu("Gameplay/Character Settings")]
public sealed class CharacterSettings : MonoBehaviour
{
    [Title("角色", "条件、验证与操作")]
    [Required("名称不能为空")]
    [LabelText("显示名称")]
    public string displayName = "Hero";

    public bool advanced = true;

    [ShowIf(nameof(advanced))]
    [Range(0, 20)]
    [Clamp(1, 12)]
    public Fix64 speed = 5;

    [Dropdown(nameof(Profiles), true)]
    public string profile = "Balanced";

    [ValidateInput(nameof(IsPositive), "等级必须大于 0")]
    public int level = 1;

    [ProgressBar(0, 100, "生命")]
    [InlineButton(nameof(Heal), "回满")]
    public Fix64 health = 75;

    private IEnumerable<string> Profiles =>
        new[] { "Balanced", "Quality", "Performance" };
    private bool IsPositive(int value) => value > 0;
    private void Heal() => health = 100;
}

编辑器完整工作流

  1. 在运行时程序集的可序列化字段上添加一个 Attribute，禁止引用 BEngine.Editor。
  2. 等待编译并在 Inspector 验证基础字段，再逐步组合条件、验证和布局。
  3. Provider 使用实例字段、属性或零参非 void 方法，返回 IEnumerable。
  4. Validator 使用 bool M() 或 bool M(T value)；InlineButton 使用 void M() 或 void M(T value)。
  5. 路径字段选择后检查返回路径；relativeToProject 默认为 true。
  6. 自定义 Drawer 放在 Editor 程序集，所有不支持的 propertyType 回退 DefaultPropertyField。
  7. GetPropertyHeight 覆盖所有额外行，并在多选、窄 Inspector、滚动和脚本重载后验证。
  8. Play 仅用于调试；停止后在 Edit Mode 保存 Scene 或资源。

如何扩展：可运行 Percent Drawer

运行时程序集

using System;
using BEngine;

[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property)]
public sealed class PercentAttribute : PropertyAttribute;

Editor 程序集

using System;
using BEngine;
using BEngine.Editor;

[CustomPropertyDrawer(typeof(PercentAttribute))]
public sealed class PercentDrawer : PropertyDrawer
{
    public override void OnGUI(
        Rect position, SerializedProperty property, GUIContent label)
    {
        if (property.propertyType != SerializedPropertyType.Float)
        {
            EditorGUI.DefaultPropertyField(
                position, property, label, includeChildren: true);
            return;
        }

        var percent = Math.Clamp(property.floatValue * 100f, 0f, 100f);
        property.floatValue = EditorGUI.Slider(
            position, $"{label.text} (%)", percent, 0f, 100f) / 100f;
    }
}

[CustomPropertyDrawer] 是注册方式。Editor asmdef 必须引用定义 PercentAttribute 的运行时程序集；程序集重载后 Registry 会重新扫描。
