Lighting2D

Enable com.bengine.lighting2d. Add Rendering / 2D Light for Global, Point, Spot, Freeform or Sprite illumination.

Freeform authoring

Use a simple outline of 3–128 local vertices. Enable Edit outline in Scene and drag handles; Escape cancels and Undo reverses a complete drag. Insert midpoint and Remove selected point edit topology. Invalid self-intersections, duplicate edges and zero-area outlines are rejected. Falloff extends outside the outline in world units.

Sprite lights

Assign a Sprite and its local size. The cookie's color, alpha, pivot and atlas rectangle are respected, including rotated or mirrored light transforms. Six distinct cookie textures can affect a target layer; multiple sprites in one atlas share a slot.

Normal maps

Add Rendering / 2D Normal Map on the rendered object. Assign a linear tangent-space RGB normal image, set strength and UV scale/offset, and adjust light height. Sprite flips and rotation transform the normal direction. Ambient/global lighting remains unchanged.

Persistence and queries

Scene saving and content builds retain normal/cookie references and outline data. CPU Sprite queries require Read/Write texture data; rendering does not. CPU Lighting2D.Evaluate omits the rendered object's normal map. See the package Readme for limits and validation scope.
