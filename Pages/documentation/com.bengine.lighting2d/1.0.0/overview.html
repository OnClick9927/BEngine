Lighting2D

2D lights, ambient lighting, shadows, Sprite cookies and normal maps.

Enable com.bengine.lighting2d in Package Manager. Disabling the package removes its tools and types from the project.

Add Rendering / 2D Light. Global, Point and Spot remain available. Freeform lights use a simple concave or convex outline with 3..128 local vertices and an outward falloff distance in world units. In the Inspector, enable Edit outline in Scene, drag points, or insert/remove points. One drag is one Undo operation; Escape cancels it. Self-intersecting, duplicate-edge or zero-area outlines are rejected before replacing the current outline. Editing is disabled during Play.

Sprite lights use a Sprite's color and alpha as the light cookie. Set spriteSize in local units; the Sprite pivot, atlas rectangle and light's transform determine its placement. An absent Sprite emits no light. Multiple Sprite lights can share one atlas texture. A target layer supports six distinct cookie textures at once; exceeding this produces an explicit error.

Add Rendering / 2D Normal Map on a rendered object and assign a normal Texture. Store tangent-space XYZ in RGB, use a linear texture, and match the diffuse UV layout (or set uvScale/uvOffset). Strength scales the tangent XY components. Sprite flips, rotation and mirrored scale transform the tangent basis. The light's positive height determines its normal direction; height is used only for the 2D lighting calculation. Ambient/global illumination remains independent of the normal map.

Point, Spot, Freeform and Sprite lights support existing layer filters and shadow outlines. Vulkan/OpenGL sample albedo, normal and cookie textures independently; changing or disposing a texture preserves already recorded draws. The per-draw light/outline data budget is 64 KiB, with explicit rejection if exceeded.

Light.GetIntensityAt and Lighting2D.Evaluate offer CPU shape/cookie queries. Sprite cookie CPU queries require the texture's Read/Write setting; GPU rendering does not. CPU evaluation does not sample a rendered object's normal map. Scene serialization preserves shape vertices, masks and texture references, and the content build includes referenced normal/cookie assets.

Windows validation lives in Temp/Validation/LightingEnhancements; the shared eight-slot texture regression is in Temp/Validation/DesktopGraphics. Other platform devices require separate verification.
