Particles2D

Enable com.bengine.particles2d and add Effects / Particle System 2D. Animation supplies the shared curves.

Emission and lifetime

Use rate emission or Bursts with time, count, repeats and probability. Looping systems repeat the Burst schedule each duration. Size, velocity, angular speed and trail width use curves; color uses gradient keys. Lifetime keys range from 0 to 1. Inspector edits and nested keys support Undo and scene saving.

Sub-emitters and collision

Reference a system in the same scene and choose Birth, Death or Collision, count, color and velocity inheritance. Disable playOnAwake for systems used only by a parent. Cycles are rejected. The optional Particle Physics 2D provider adds swept collider queries, masks and trigger filtering; enable collision on the particle system and configure bounce, damping and lifetime loss.

Trails and playback

Trails can remain after particle death, with bounded samples and independent lifetime. Pause freezes simulation. Play resumes. Stop(false) drains existing particles; Stop() clears particles and trails. Prewarm applies to looping playOnAwake systems.

Preview

Enable Edit Mode Preview and scrub Time (up to 3600 seconds). Sub-emitters and authored scene collision participate. A fixed random seed allows repeatable sampling. Save, serialized edits, Inspector close and Play entry clear preview state. See the package Readme for behavior and validation scope.
