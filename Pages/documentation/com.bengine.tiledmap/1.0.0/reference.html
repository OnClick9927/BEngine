TiledMap稀疏 Tilemap、Atlas Palette、编辑器画笔与合批渲染

运行、分包与验证

TilePalette 描述贴图与 TileDefinition 的 atlas 区域。Tilemap 保存坐标与图块，TilemapRenderer 参与场景排序与相机裁剪。ITilemapTextureSource 隔离纹理字节来源；GPU 上传在缓存缺失时执行，资源缓存代次变化会释放旧贴图。

快速开始

  1. 导入无压缩像素 atlas 并建立 Palette，明确图块宽高、留边、间距和坐标原点，先只绘制一个图块核对 UV。
  2. 创建 Tilemap 与 TilemapRenderer，在 Tile Palette 窗口选择图块和绘制工具；使用实际 Sprite 的 pixelsPerUnit 配合相机 assetsPPU。
  3. 用 RuntimePainting 示例验证运行时写入和清除；在地图边界移动相机检查裁剪、图块变换和排序。

扩展与平台接口

运行时使用 Fix64 和主线程 BTask；通过平台服务读写资源，不直接创建主机文件或网络连接。编辑器代码放在 Editor 装配，停止场景时取消请求并解除订阅。

资源分包与更新

AssetImporter.assetBundleName/assetBundleVariant 指定资源组；BuildPipeline.BuildAssetBundles 接受导入设置或 AssetBundleBuild[]。跨包引用记录为目录依赖。RequiredBundleNames 控制首次安装，IAssetBundleDownloadManager 下载可选组和依赖。已安装可选包参与之后的版本更新。

行为边界

瓦片采样固定为 Point/ClampToEdge，适合像素 atlas；没有自动透明边缘扩展或任意纹理过滤切换。旋转/非整数缩放会改变像素覆盖，PixelPerfectCamera 只吸附图块中心。地图渲染仍需处理可见格子数量，避免每帧重建整张 Palette。

排查与验证

  • 图块边缘出现邻图颜色：检查 atlas UV、间距和边缘填充；不要对像素图使用双线性缩放。
  • 热更新后仍是旧图：资源更新必须通过引擎激活目录或 BAsset 缓存失效路径，自定义源更新时也应触发同一机制。
  • 地图闪烁或排序错误：确认 TilemapRenderer 的排序层和顺序，与普通 SpriteRenderer 使用一致的层配置。
  • 对相机施加小于半个源像素的移动，比较开启吸附前后图块边缘稳定性。
  • 以相同路径激活新纹理，确认下一帧替换 GPU 贴图；在大小写敏感资源源上分别测试不同大小写路径。
  • 用密集可见地图记录稳态分配；四角与 UV 使用栈内缓冲，顶点 List 保留容量供后续帧复用。

TiledMap 使用手册

TiledMap 提供稀疏整数网格、TilePalette YAML 资源、TextureAtlas 导入、 Scene 选取/Gizmos、可撤销画笔和基于相机的批量渲染。Tile ID 0 永远表示空单元。

SpriteRenderer 只引用 Sprite；图集关系由 SpriteAtlas 资源持有 Sprite 引用决定。 TiledMap 的 Palette 可以导入 TextureAtlas，并把其 Sprite UV 转换为 TileDefinition。

快速开始

  1. 在 Window > General > Package Manager 启用 Tiled Map。
  2. 从 Examples 导入 Atlas Palette。
  3. 打开 Assets/Examples/AtlasPalette/res/AtlasPalette.scene.yaml。
  4. 打开 Window > 2D > Tile Palette，载入示例 tilepalette.yaml。
  5. 也可在 Project 右键或顶部 Assets 使用 Create > 2D > Tile Palette 新建资源。
  6. 选择 Hierarchy 中的 Atlas Tilemap；窗口右侧网格随即成为绘制目标。
  7. 选择 Tile，切换 Paint/Erase/Flood 与 Transform Flags，点击网格；操作支持 Undo。
  8. 保存 Palette 与场景，进入 Play，在 Game 验证 Camera2D 裁剪和排序。

Play 中 SetTile/BoxFill 只修改运行时场景镜像，停止后会丢弃。 要持久化地图，请在编辑模式使用 Tile Palette 窗口并保存 scene.yaml。

组件与资源介绍

Tilemap

paletteAsset、cellSize、cellGap、tileAnchor 与稀疏 TileCell 集合。提供坐标转换、读写、区域填充、洪泛、替换与 Bounds。

TilemapRenderer

继承 Renderer2D；配置 sortingLayer、 orderInLayer、opacity、material、color、sortOrder 和 cullOutsideCamera。

TilePalette

Name、Atlas、Columns、Rows、Tiles。 SliceAtlas 规则切片；ImportAtlas 从 TextureAtlas 的 Sprite 名称和 UV 生成定义。

TileDefinition / TileCell

Definition 保存正 ID、Name、Texture、 归一化 UV、RGBA Tint 和 HasCollider；Cell 保存坐标、Tile ID、Tint 与 Transform Flags。

Transform Flag用途
FlipX / FlipY不增加图集 Sprite 的水平/垂直镜像。
Rotate90 / Rotate180按 2D 单元中心旋转；可与 Flip 组合。
None按 Palette UV 原样绘制。

编辑器绘制工作流

  1. 使用 GameObject > 2D Object > Tilemap 创建带 Tilemap + TilemapRenderer 的对象。
  2. 使用 Assets/Create/2D/Tile Palette 创建 Palette，打开 Window/2D/Tile Palette。
  3. 设置 Atlas 工程路径和 Columns/Rows，点击 Slice Atlas；若路径为 .atlas.yaml，点击 Import Texture Atlas 直接采用图集 Sprite。
  4. 选择 Tile，修改 Tile Name 与 Collider 标记并保存 Palette。
  5. 选中 Tilemap 对象，点击 Assign Current Palette。
  6. 用 Paint、Erase、Flood 编辑单元；用 Transform 下拉设置旋转/翻转；Box Fill 批量填充。
  7. 每次绘制都会 Undo.RecordObject、SetDirty 并 Repaint Scene；Ctrl+Z 可撤销。

等距、六边形与 Prefab 笔刷

Tilemap 的 cellLayout 支持 Rectangle、Isometric、HexagonPointTop 和 HexagonFlatTop。cellSize 是格子轮廓的包围尺寸；默认锚点为 (0.5,0.5)。非矩形原点格中心为 (0,0)，六边形使用轴坐标 (q,r)，Flood 沿六个相邻格传播。

渲染、Scene 拾取和碰撞采用真实菱形/六边形轮廓，支持旋转、镜像和非等比缩放；UV 按轮廓包围矩形映射。等距和六边形碰撞不会按矩形合并。旧地图默认保持 Rectangle。

Tile Palette 的 Prefab Brush 选择 Prefab 后，可用 Paint、Erase 和 Box Fill 在 Scene 创建保留来源的子对象，支持拖动补点和整笔 Undo/Redo。清空字段恢复瓦片绘制。保存重载后仍可按格子擦除；普通子对象不受影响。Prefab 笔刷不支持 Flood/Pick/Move，改变网格布局不会重新摆放既有 Prefab。

渲染顺序与合批

Tile 单元与 Sprite、Particle、UI 一样进入统一 2D 排序：Sorting Layer → Order In Layer → Hierarchy → 透明度/稳定顺序。TilemapRenderer 的 sortOrder 决定同一 Tilemap 内单元遍历方向。 Camera2D cullingMask 必须包含 Renderer 的世界层；cullOutsideCamera 会在提交前剔除视口外单元。

能否合批由 Material + Shader + Atlas/Texture 决定。相邻 Tile 使用同一 Renderer Material 和同一 Palette Atlas 时可共享 Batch；不同材质、Shader 或 Texture 会断开。透明度和排序约束 仍优先于合批，不能为减少 Draw Call 改变正确的视觉顺序。

如何扩展

自定义生成器

  1. Runtime asmdef 引用 BEngine.TiledMap。
  2. 缓存 Tilemap，用确定性种子生成 TileCoordinate 序列。
  3. 批量使用 BoxFill/SwapTile，完成后一次 RefreshAllTiles。
  4. 需要临时 Palette 时使用 SetPaletteOverride；需要资源持久化时只在编辑模式 Save。

自定义编辑器工具

把窗口/菜单放入 Editor asmdef。编辑前调用 Undo.RecordObject， 修改后 EditorUtility.SetDirty(tilemap) 与 SceneView.RepaintAll。Asset 创建命令使用 AssetDatabase.GenerateUniqueAssetPath，顶部 Assets 菜单与 Project 右键会自动共享外部 MenuItem。

排错

只显示检查纹理Palette.Atlas 未设置或路径错误；指定 PNG/TextureAtlas 并保存 Palette。
画笔没有目标在 Hierarchy 选择带 Tilemap 的 GameObject。
Tile 不显示确认 ID 大于 0、Palette 中存在定义、Camera mask 包含 sortingLayer、opacity 非 0。
合批被拆开比较 Material、Shader、Atlas/Texture 和排序连续性。
Play 后地图恢复运行时隔离的预期行为；在编辑模式绘制并保存场景。
