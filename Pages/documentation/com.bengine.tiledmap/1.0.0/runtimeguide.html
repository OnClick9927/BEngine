TiledMap 运行与扩展指南

TMX/TMJ 普通对象支持等距地图的坐标和轮廓投影，按 tilewidth/tileheight 保留菱形比例。对象层 offset 为屏幕坐标。导入默认创建 PolygonCollider2D / EdgeCollider2D；点对象没有碰撞体，属性 collider=false 可关闭自动创建，isTrigger=true 可创建触发器。TiledFileImporter.Import(path, scene, pixelsPerUnit, false) 可关闭整次导入的碰撞生成。Inspector 可为没有碰撞体的对象补建，并支持 Undo。图块对象、模板及无限地图仍按既有边界处理。

包 ID：com.bengine.tiledmap。运行时命名空间：BEngine.TiledMap。数值基于 Fix64；使用引擎已有的组件、资源、场景和服务接口。

快速开始

  1. 在 Package Manager 启用 TiledMap，检查依赖与 Console 编译结果；导入 AtlasPalette、RuntimePainting 示例。

  2. 从 Project 打开示例的 res 场景，在 Hierarchy 检查对象及父子关系。

  3. 同时观察 Scene 与 Game，在 Inspector 检查引用，点击 Play；完成后 Stop，并确认编辑模式资源未被运行时状态污染。

  4. 导入无压缩像素 atlas 并建立 Palette，明确图块宽高、留边、间距和坐标原点，先只绘制一个图块核对 UV。

  5. 创建 Tilemap 与 TilemapRenderer，在 Tile Palette 窗口选择图块和绘制工具；使用实际 Sprite 的 pixelsPerUnit 配合相机 assetsPPU。

  6. 用 RuntimePainting 示例验证运行时写入和清除；在地图边界移动相机检查裁剪、图块变换和排序。

组件与 API

主要类型：TilePalette、TileDefinition、Tilemap、TilemapRenderer、TileCoordinate、TileTransformFlags、TilemapLayout、TilemapGeometry、TilemapPrefabInstance、ITilemapTextureSource。

cellLayout 支持矩形、等距、尖顶/平顶六边形；六边形为轴坐标。LocalToCell / WorldToCell 以网格原点拾取，GetCellLocalOutline 返回含锚点偏移的图块轮廓；GetNeighbors 返回四/六个相邻格。渲染先旋转图块，再应用地图及父级变换，保证非等比缩放/镜像与碰撞一致。坐标、锚点、Prefab 笔刷及已知限制详见包 Readme。

TilePalette 描述贴图与 TileDefinition 的 atlas 区域。Tilemap 保存坐标与图块，TilemapRenderer 参与场景排序与相机裁剪。ITilemapTextureSource 隔离纹理字节来源；GPU 上传在缓存缺失时执行，资源缓存代次变化会释放旧贴图。

var tilemap = scene.CreateGameObject("Map").AddComponent<Tilemap>();
var renderer = tilemap.gameObject.AddComponent<TilemapRenderer>();
var pixel = camera.gameObject.AddComponent<PixelPerfectCamera>();
pixel.assetsPPU = 16;
pixel.refResolutionX = 320;
pixel.refResolutionY = 180;

代码片段中的 scene、camera、资源和业务对象应来自当前场景。先确认资源加载成功再赋值；不要把资源失败吞掉后继续运行。运行时代码放进项目 runtime/Scripts 对应的 asmdef，编辑器工具放进 Editor 装配。

生命周期与确定性

使用 Awake 获取依赖，Start 初始化首次运行状态。启用较晚的对象仍应在首次 Update 前执行一次 Start。物理操作在 FixedUpdate，普通状态推进在 Update，相机最终跟随在 LateUpdate。通过 BTask 和 BCancellationToken 编排主线程异步流程；退出场景时取消未完成请求并解除事件订阅。

多个 SceneRuntime 应使用 TickAll 共享一次全局帧推进。录制固定输入、固定步长和资源版本后再比较结果；不要使用主机墙上时钟、后台线程或网络返回时刻直接修改模拟状态。视觉与音频的硬件输出不作为确定性逻辑输入。

资源分包与更新

在 AssetImporter 设置 assetBundleName/assetBundleVariant，使用 BuildPipeline.BuildAssetBundles 或播放器构建流程产生目录。跨包序列化引用会加入依赖，公共资源应分配到稳定的共享包，避免重复归属与循环依赖。需要精确构建范围时传入 AssetBundleBuild[]。

首次安装可设置 AssetBundleRuntimeOptions.RequiredBundleNames；null 表示完整安装。通过 IAssetBundleDownloadManager.GetDownloadSizeAsync 估算某组及其依赖的缺失字节，再调用 DownloadDependenciesAsync 获取可选内容。更新目录激活后，已安装可选包继续参与更新。下载完成与目录激活属于不同阶段，失败时不得先切换到不完整资源版本。

本包使用的资源、着色器及其元数据必须随包导出。以相同路径替换内容后检查 BAsset 缓存代次和运行时重新绑定；已有对象持有的资源引用不等于自动替换该对象的所有字段。请在更新成功的明确时机刷新相关资源。

平台与扩展

业务代码通过 FileUtility/PathUtility 调用文件和路径能力；网络功能使用所属包的 IHttpTransport、IWebSocketTransport、ITcpTransport/IUdpTransport 或包自身的服务接口。Windows/.NET 等平台适配器处理实际文件、套接字及硬件；引擎在 Poll 中交付网络结果。扩展平台时替换服务注册，不在组件内直接创建 FileStream、HttpClient、Socket 或 Task。

为 TiledMap 增加功能时，先查阅 BEngine.TiledMap 与 BEngine.TiledMap.Editor 的现有实现、asmdef 依赖与 Editor/Examples。保留 Unity 风格命名及本引擎二维类型；新增公共字段必须具备实际行为，暂不支持的能力应明确报错或写入限制说明。

行为边界

瓦片采样固定为 Point/ClampToEdge，适合像素 atlas；没有自动透明边缘扩展或任意纹理过滤切换。旋转/非整数缩放会改变像素覆盖，PixelPerfectCamera 只吸附图块中心。地图渲染仍需处理可见格子数量，避免每帧重建整张 Palette。

排查顺序

  • 图块边缘出现邻图颜色：检查 atlas UV、间距和边缘填充；不要对像素图使用双线性缩放。
  • 热更新后仍是旧图：资源更新必须通过引擎激活目录或 BAsset 缓存失效路径，自定义源更新时也应触发同一机制。
  • 地图闪烁或排序错误：确认 TilemapRenderer 的排序层和顺序，与普通 SpriteRenderer 使用一致的层配置。

遇到异常时记录最小场景、包版本、平台、步长、资源路径和调用顺序。在 Console 保留第一条异常及堆栈；先复现单对象问题，再逐步恢复完整场景。画面问题应同时保存原始分辨率截图与采样配置。

验证清单

  • 对相机施加小于半个源像素的移动，比较开启吸附前后图块边缘稳定性。

  • 以相同路径激活新纹理，确认下一帧替换 GPU 贴图；在大小写敏感资源源上分别测试不同大小写路径。

  • 用密集可见地图记录稳态分配；四角与 UV 使用栈内缓冲，顶点 List 保留容量供后续帧复用。

  • 在 Editor Play 和导出的 Windows Player 各运行一次，不以编辑器能加载资源推断包内资源完整。

  • 分别测试冷启动、重复启停、资源更新后重启、失败后重试；记录实际执行的平台，未运行的移动端不能标为通过。

  • 使用固定输入测稳态 Update/Render 的分配与耗时。首次资源解码、着色器编译和缓存预热应单独记录。

Skills 与示例

本包额外提供 bengine-tiledmap-authoring、bengine-tiledmap-runtime 与 bengine-tiledmap-validation 三个任务入口，分别覆盖配置、实现与验证。示例通过 Package Manager 导入为独立目录；先运行原始示例，再修改一个参数观察差异，保留原始资源 GUID 以验证重复导入行为。
