Sprite Skinning 2D

Sprite Skinning 2D provides a complete 2D skeletal workflow for BEngine:

  • Create and edit ordered bone hierarchies.
  • Edit polygon vertices, UVs, triangles, and up to four normalized weights per vertex.
  • Generate distance-based weights and paint a selected bone's influence in the Scene view.
  • Create and bind a scene skeleton from an asset.
  • Deform textured triangle meshes at runtime on Vulkan, OpenGL, Direct3D, and WebGPU.
  • Solve two-bone limbs or constrained arbitrary chains, apply transform constraints and FFD, and switch named texture attachments at runtime.

Open Window > 2D > Sprite Skinning or double-click a .spriteskin.yaml asset. The editor blocks asset and scene writes while Play mode is active.

See Doc/SpriteSkinning2D.md for the asset model and runtime examples.
