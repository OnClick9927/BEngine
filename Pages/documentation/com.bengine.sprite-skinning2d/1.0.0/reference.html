Sprite Skinning 2D

Author weighted 2D meshes, bone hierarchies, attachments, free-form deformation, two-bone or constrained chain IK, and transform constraints with runtime rendering.

Workflow

  1. Create a .spriteskin.yaml asset.
  2. Edit bones, vertices, triangles, UVs, and weights in Window > 2D > Sprite Skinning.
  3. Add SpriteSkin2D to a GameObject and create or bind its skeleton.
  4. Animate bone transforms, add LimbIK2D, ChainIK2D, or TransformConstraint2D where needed, and switch attachments by name.

The asset format is deterministic and supported by project assets, bundles, and exported Players.
