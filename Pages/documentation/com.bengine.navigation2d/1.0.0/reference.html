Navigation2D确定性网格烘焙、A* 寻路与 2D Agent

运行、分包与验证

Surface.BuildNavigation 重建格子；Navigation2D.CalculatePath/SamplePosition 使用区域掩码。Agent.SetDestination 返回是否找到可用路径；SetPath 保留独立副本；remainingDistance/velocity/pathStatus 描述运动状态。updatePosition=false 时通过 nextPosition 获取模拟位置。

快速开始

  1. 创建 Surface，设置 bounds/cellSize 和障碍层，添加 Collider2D 障碍后执行 Bake。先观察烘焙结果，再创建 Agent。
  2. 用 SamplePosition 验证目标落在可行走区域，给 SetDestination 的返回值和 pathStatus 加日志。PathPartial 只能走到已找到的可达点。
  3. 用 Modifier 设置区域并用 areaMask 过滤；添加 Link 连接两个区域，重建 Surface 后验证单向/双向和 costModifier。

扩展与平台接口

运行时使用 Fix64 和主线程 BTask；通过平台服务读写资源，不直接创建主机文件或网络连接。编辑器代码放在 Editor 装配，停止场景时取消请求并解除订阅。

资源分包与更新

AssetImporter.assetBundleName/assetBundleVariant 指定资源组；BuildPipeline.BuildAssetBundles 接受导入设置或 AssetBundleBuild[]。跨包引用记录为目录依赖。RequiredBundleNames 控制首次安装，IAssetBundleDownloadManager 下载可选组和依赖。已安装可选包参与之后的版本更新。

行为边界

采用离散格网而非 Unity 多边形 NavMesh。Agent 半径参与局部避让，格网净空取决于 Surface 烘焙配置。局部避让是轻量的二维排斥，不是 ORCA，也不保证密集队列无死锁。不同 avoidance quality 当前不提供不同求解器。不要把区域编号直接当掩码，使用 1UL << area。

排查与验证

  • 目标在障碍中：允许得到 PathPartial；不得把阻挡中的原始目标追加到路径末尾。
  • 高速角色越过终点：核对 stoppingDistance、autoBraking 与每步位移限制，运动应被当前拐点距离截断。
  • 障碍移动后仍走旧路：更新障碍并 BuildNavigation；autoRepath 监听烘焙代次，不能代替烘焙。
  • 分别测试 mask=0、仅某区域、全区域和不可达目标，检查返回值与 pathStatus。
  • 设很大 speed 和较大 Tick，确认不会越过拐点，在终点速度归零。
  • 修改传给 SetPath 的原始 corners 后，确认 Agent 的路径不改变；重烘焙后检查 autoRepath。

Navigation2D 使用手册

Navigation2D 将场景中的 2D Collider、Obstacle 和 Modifier 采样为确定性网格， Agent 使用 A* 计算路径并在固定点数坐标中移动。包依赖 Physics2D，启用本包时 Package Manager 会同时解析运行时依赖。

坐标、速度、网格单元与路径长度都使用 Fix64。相同场景、输入和固定时间步应得到相同结果。

快速开始

  1. 打开 Window > General > Package Manager，选择 2D Navigation 并启用。
  2. 切到 Examples，在 Navigation Surface And Agent 后点击 Import。
  3. 在 Project 打开 Assets/Examples/NavigationSurfaceAndAgent/res/Navigation.scene.yaml。
  4. 选择 Navigation Surface，确认 Size 覆盖场景，Cell Size 与 Agent Radius 合理。
  5. 通过组件菜单执行 Bake；Scene 中的 Gizmos 会显示 Surface、Obstacle、Agent 和 Link。
  6. 点击 Play，Agent 会绕开红色 Carving Obstacle。按 Space 在两个目的地之间切换。
  7. 观察 Console 的目标、路径状态与 remainingDistance；停止 Play 后场景恢复到运行前。

修改障碍物后必须再次 Bake 或调用 UpdateNavigation。运行时烘焙只修改 Play 镜像， 不会保存到场景资源。

组件介绍

NavigationSurface2D

定义采样范围和网格精度。关键字段： agentTypeId、collectObjects、center、size、layerMask、useGeometry、cellSize、agentRadius、 buildOnStart。Context 菜单提供 Bake 与 Clear。

NavigationAgent2D

沿路径移动。配置 radius、speed、acceleration、 angularSpeed、stoppingDistance、autoBraking、autoRepath、updatePosition、updateRotation、 areaMask 与 avoidance quality。

NavigationObstacle2D

Box/Circle 动态障碍。center、size/radius、 carving 与 carveOnlyStationary 决定烘焙时的阻挡形状。

Link 与 Modifier

NavigationLink2D 连接 startPoint/endPoint，可双向并设置 cost； Modifier2D 可结合 Collider 覆盖区域；ModifierVolume2D 以 center/size 标记 Area。

字段选择建议

参数影响建议
cellSize越小路径越精细，节点数和烘焙成本越高从角色直径的 1/2 开始
agentRadius对阻挡区域增加安全边距与 Agent radius 保持一致
stoppingDistance到目标多近才结束路径避免小于一个 Fix64 有效步长
layerMask选择参与 Surface 收集的世界层只包含导航几何层，减少误阻挡

编辑器工作流

  1. 用 GameObject 创建地面和障碍，为需要参与采样的对象添加 Physics2D Collider。
  2. 创建空 GameObject，使用 Add Component 的 AdvancedDropdown 搜索 Navigation Surface 2D。
  3. 在 Scene 中观察 Surface Gizmo，调整 center/size；用 Hierarchy 左侧眼睛临时隐藏干扰物。
  4. 为阻挡物添加 Navigation Obstacle 2D，开启 carving；为角色添加 Navigation Agent 2D。
  5. 从组件 Context 菜单 Bake。更改 Collider、Obstacle、Modifier 或 Surface 后重新 Bake。
  6. 进入 Play，在 Scene 打开 Navigation Gizmos，在 Game 观察相机结果，在 Console 检查状态。

运行时 API

API用途
Navigation2D.CalculatePath(source, target, mask, path)计算路径并写入 NavigationPath2D。
Navigation2D.SamplePosition(point, out hit, distance, mask)将任意点吸附到最近可行走网格。
agent.SetDestination(target)计算并采用目标路径，返回是否成功。
agent.SetPath / ResetPath / Warp采用自定义路径、清除路径或瞬移并清除旧路径。
surface.BuildNavigation / UpdateNavigation / RemoveData构建、重建或清除运行时网格。
using BEngine.Navigation2D;
using Nav = BEngine.Navigation2D.Navigation2D;

public sealed class ClickToMove : MonoBehaviour
{
    private NavigationAgent2D? agent;
    public override void Awake() => agent = GetComponent<NavigationAgent2D>();

    public void MoveTo(Vector2 requested)
    {
        if (agent is null) return;
        var target = Nav.SamplePosition(requested, out var hit, 2)
            ? hit.position
            : requested;
        if (!agent.SetDestination(target))
            Debug.LogWarning("No complete path to target.");
    }
}

如何扩展

扩展一个运行时目标选择器

  1. 在项目 Runtime asmdef 引用 BEngine.Navigation2D。
  2. 创建 MonoBehaviour 并缓存 NavigationAgent2D，不要每帧重复搜索组件。
  3. 把输入位置先交给 SamplePosition，再调用 SetDestination。
  4. 通过 hasPath、pathPending、pathStatus、remainingDistance 驱动动画或 UI。
  5. 需要动态地图时集中调用 Surface.UpdateNavigation，不要让每个 Agent 独立重烘焙。

扩展编辑器工具

在 Editor asmdef 引用 Navigation2D.Editor，使用 MenuItem 把命令放到 Tools/项目名 下； 通过 Selection.activeGameObject 获取目标，在修改场景组件后标记场景为已修改。外部组件可实现 OnDrawGizmosSelected 绘制目标与路径，用户可在 Scene 的 Gizmos 菜单按组件类型开关。

调试、限制与常见问题

SetDestination 返回 false确认 Surface 已 Bake、源点/终点可采样、Area Mask 匹配且对象属于同一运行场景。
Agent 穿过障碍确认 Obstacle carving 开启，或 Collider 位于 Surface.layerMask；移动后重烘焙。
路径贴墙增大 Surface.agentRadius 或 Agent.radius，减小 cellSize 后重烘焙。
Scene 没有 Gizmos开启 Scene Gizmos，并在类型列表启用 NavigationSurface2D/Agent/Obstacle/Link。
停止 Play 后数据消失这是运行时镜像隔离的预期行为；在编辑模式配置并保存资源。
