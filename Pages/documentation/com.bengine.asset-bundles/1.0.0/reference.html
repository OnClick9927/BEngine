AssetBundles

AssetBundle Package 按资源组进行增量构建：一个包包含多个 Bundle，未变化的压缩产物会在校验后复用。

配置与构建

打开编辑器菜单 Assets → AssetBundle Packages...，配置包名与资源目录或文件，保存至 ProjectSettings/AssetBundlePackages.yaml。

format: BEngine.AssetBundlePackages
version: 1
defaultPackageName: default
packages:
  - name: fonts
    assetPaths: [Assets/GameContent/Fonts]
  - name: images
    assetPaths: [Assets/GameContent/Images]
  - name: config
    assetPaths: [Assets/GameContent/Config]

路径最长匹配优先；没有匹配的资产进入默认包。资源导入器的 Bundle 名决定包内分组。bengine 是自动生成的程序集和引擎资源保留包。

首次执行 Build All Packages 建立完整基线。修改配置后选择 config，执行 Build Selected Packages，字体、图片复用已校验缓存。未选包有变化、缺失或损坏时会报错，需把该包纳入构建。

缓存位于 Library/AssetBundleBuildCache，不随 Player staging 删除。输入内容、导入设置、依赖、平台、压缩、加密和构建器变更都会影响指纹；复用时会核对大小与 SHA-256。

运行时

构建时明确区分包，运行时继续使用同一 manager 和原资源 address。只有按包更新、下载或修复时才需要指定包名；普通加载无需感知包归属。
