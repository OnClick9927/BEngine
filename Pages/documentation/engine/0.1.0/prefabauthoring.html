Prefab、Variant 与覆盖项

通过 GameObject > Prefab > Save As Prefab Asset 创建普通 Prefab。选中连接的实例后，Save As Variant 将当前修改保存为独立资源并连接到 Variant；基资源不会被覆盖。Variant 可以继续派生 Variant。

将 Prefab 实例放到另一个 Prefab 的层级下再保存，会保留嵌套来源。同一个 Prefab 可以嵌套多次；实例身份、内部 GameObject/Component 引用和局部覆盖互相独立。

GameObject > Prefab > Overrides 或 Inspector 的 Prefab 更多菜单打开小型 Overrides 窗口。窗口列出对象/组件的修改属性，以及新增/移除的组件、对象。属性和组件支持逐项 Apply/Revert；对象层级的增加/删除使用 Apply All/Revert All。窗口提供 Refresh，操作失败时显示原因。

Apply 修改对应源资源；Revert 恢复源资源数据。整实例 Revert 保留仍存在的 GameObject、Transform 和 Component 身份，场景里指向这些对象的引用继续有效。新增/删除的结构和修改值支持 Undo/Redo。Outermost Unpack 保留内部嵌套 Prefab，Complete Unpack 移除所有连接。Play 模式禁止这些制作写入。

持久化与继承

Prefab v3 保存来源引用、实例身份映射、来源快照和当前层级。重新实例化或加载场景时比较快照与当前层级，再合入最新源资源，保留覆盖项并继承未修改的字段、组件和子对象。已存在对象保持 ID，新继承对象使用稳定派生 ID。Prefab v2 仍能读取。

导入后的来源使用 GUID，移动资源和其 .meta 后仍能解析。尚未导入的独立文档使用文件路径；在导入前移动这些文档需要同步路径。缺失来源或循环继承会报错，不会静默退化为丢失来源的副本。Prefab 内部对象引用可持久化，指向层级外场景对象的引用会在保存前被拒绝。

共享/循环的托管对象按相互引用的字段组保持一致；这组数据被覆盖时作为整体保留，不会把多个来源捕获中的临时引用编号混合。与该组无关的字段仍继续继承。Tag/Layer 项目迁移同时更新来源快照，避免全局重命名被误认为实例覆盖。

来源导入或项目刷新后，编辑器在下一次更新合并所有打开场景和 Prefab Stage 中的实例；编译、资源更新和 Play 期间延后处理。刷新保留实例身份、局部覆盖和场景外部引用，不创建用户 Undo 记录。保存 Prefab Stage 后只更新来源快照时不会再次标记为未保存。来源无效或新组件构造失败会回滚实例，修复来源后可以继续刷新。Overrides 列表随 Undo/Redo 刷新。

API 与检查

  • PrefabUtility.SaveAsPrefabVariant(instanceRoot, assetPath, connect) 创建 Variant。
  • GetOverrides(root, includeDefaultOverrides) 返回属性、组件和层级差异；默认忽略根 Transform 的位置/旋转，传入 true 包含这些差异。
  • ApplyPropertyOverride / RevertPropertyOverride 操作单个已提交的 SerializedProperty；先提交 SerializedObject 中的待编辑值。
  • ApplyObjectOverride / RevertObjectOverride 操作对象或组件的字段；ApplyOverride / RevertOverride 也处理组件增删。
  • LoadPrefabContents 返回制作副本，用完后调用 UnloadPrefabContents，不保留临时层级。
  • RefreshPrefabInstance(root) 主动合入来源变化；没有变化时返回 false。
