下载 Hub，准备环境。

当前入门流程面向 Windows。下载并运行 BEngine.Hub.exe，在「更新」中安装引擎和所需扩展包。Hub 会检测运行环境，并引导你补齐缺少的组件。

下载与环境要求→

给你的想法，一个工程。

  1. 在 Hub 中选择已安装的引擎版本。
  2. 在「工程」中新建工程；或点击「打开」，选择包含 Project.yaml 的工程文件夹。
  3. 等待编辑器完成资源导入与脚本编译，再检查 Console。

Hierarchy 显示对象层级，Project 管理资源，Inspector 用于查看和修改选中的对象。

让第一个 Sprite 动起来。

  1. 在编辑器打开 Window → Package Manager，选择 BEngine Core。
  2. 在 Examples 页签导入 Core Getting Started。
  3. 打开 Assets/Examples/CoreGettingStarted/res/Core.scene.yaml。
  4. 编译完成后点击 Play。使用方向输入移动 Sprite，按空格切换颜色。

停止 Play 后，你可以继续在编辑场景中调整对象。运行时创建的对象会随运行镜像释放。

深入使用，请从 Hub 打开文档。

在 Hub 的「引擎与包」中选择引擎版本或扩展包，再点击文档入口。Hub 会打开与该版本对应的本地手册，包含 API、详细工作流和包使用说明。

官网只介绍基础入门与功能概览；详细文档随本地安装的引擎和包提供。
