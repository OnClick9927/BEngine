01 / GET BENGINE

准备好你的创作环境。

当前入门流程面向 Windows 10 / 11。安装 .NET 10 SDK，然后从获取引擎页面下载 BEngine。也可以使用下面的命令获取源码；路径以引擎仓库为基准。

POWERSHELL
git clone https://github.com/OnClick9927/BEngine.git Engine
cd Engine
dotnet build .\src\BEngine.sln -c Release

如果你只想先体验，可以下载仓库 ZIP 并解压，再打开仓库中的 Hub。使用源码构建前，可先运行 dotnet --version 确认 SDK 已安装。

认识目录

src/ 是引擎源码，Engine/ 是导出的引擎与包。Hub 位于 Engine/BEngine.Hub.exe，项目自己的资源、设置与构建结果保存在项目目录中。

获取引擎与环境说明 ↗
02 / OPEN YOUR WORKSPACE

在 Hub 中打开你的工程。

  1. 运行引擎仓库内的 Engine/BEngine.Hub.exe。
  2. 在「引擎与包」中选择引擎版本，查看该版本可用的包。
  3. 回到「工程」，新建工程；也可以点击「打开」，选择包含 Project.yaml 的工程文件夹。
  4. 等待资源导入和脚本编译完成，在 Console 中检查编译结果。

Hub 管理工程与引擎版本。编辑器内的 Hierarchy 显示对象结构，Project 管理资产，Inspector 用于查看和修改选中对象。

↗认识编辑器与 Core组件、资源与基本工作流↗探索 Example 工程示例介绍与运行方式
03 / YOUR FIRST SCENE

让第一个 Sprite 动起来。

从引擎自带的 Core Getting Started 示例开始，无需先搭建完整游戏。

  1. 在编辑器打开 Window > Package Manager，选择 BEngine Core。
  2. 切换到 Examples 页签，在 Core Getting Started 行点击 Import。
  3. 在 Project 中打开 Assets/Examples/CoreGettingStarted/res/Core.scene.yaml。
  4. 等待脚本编译完成，点击顶部 Play 按钮，使用方向输入移动 Sprite，按空格切换颜色。
  5. 停止 Play，在 Hierarchy 和 Inspector 中观察场景对象，再打开示例脚本，了解生命周期和组件 API。
在运行中探索

Play 模式在运行镜像中执行游戏。停止后，运行时创建的对象会随镜像释放；你可以继续在编辑场景中迭代。

04 / FIND YOUR TOOLS

按项目需要，加入新的能力。

Core 提供基础场景、对象与资源能力。动画、物理、寻路、UI、音频等由扩展包提供，在项目内通过 Package Manager 管理。

先在 Hub 选择引擎版本，查看兼容包；再阅读对应包的文档，确认依赖与使用步骤。多数包提供可导入示例，适合先运行、再修改。
