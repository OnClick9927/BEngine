BEngine Animationcom.bengine.animation

固定点动画系统

Animation 包提供 AnimationClip、AnimationCurve、事件、Animator Controller、参数与状态机。运行时系统按 Scene scope 创建，并通过 ECS/兼容组件调度。

推荐工作流

  1. 在 Assets/Create 创建 Animation Clip 或 Animator Controller。
  2. 用曲线绑定目标组件字段，选择 Once、Loop、PingPong 或 ClampForever。
  3. 简单播放使用 Animation；状态切换使用 Animator。
  4. 在 Controller 中声明 Float、Int、Bool、Trigger 参数，再配置条件、退出时间和过渡时长。

运行时 API

Clip 播放

Animation 适合直接播放一个或多个 Clip，支持速度、循环、事件回调与采样。

状态机

Animator 读取 Controller，按参数和 Transition 条件进入目标状态。

var animator = GetComponent<Animator>();
animator.SetBool("Grounded", true);
animator.SetFloat("Speed", speed);
animator.SetTrigger("Jump");

确定性与资源

曲线时间、值与切线保存为 Fix64 原始值，Clip 使用 .anim.yaml，Controller 使用 .controller.yaml。资源路径应位于 Assets，构建时由包的 Document converter 验证。

Examples

Animation Getting Started 展示曲线、事件和循环播放；State Machine 展示参数、条件、Transition 与状态变化。在 Package Manager 的 Examples 页签中导入或再次导入。
