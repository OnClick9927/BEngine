# BEngine built-in icons

This directory is the single source of truth for icons shipped with BEngine.

- `BEngine.svg`: editable application-icon master.
- `BEngine.png`: 1024x1024 transparent raster asset.
- `BEngine.ico`: Windows application icon containing 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel variants.
- `BEngine.64.rgba`: embedded RGBA window icon used by Silk.NET at runtime.

Place future editor and runtime built-in icons in this directory instead of copying them into individual executable projects.
