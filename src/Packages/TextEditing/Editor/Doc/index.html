Text Editing

UI 控件共享的文本编辑机制。程序集：BEngine.TextEditing；命名空间：BEngine。

TextEditingBuffer

Synchronize 接收外部文本，Select 和 Move 控制选择与光标；ReplaceSelection 插入文本，Delete 按完整字素或单词删除；Undo/Redo 恢复编辑记录。每个控件持有独立实例。

TextElementUtility

提供 Unicode 字素簇边界、字素数量和列偏移计算，避免拆开组合字符或 emoji。

本包不创建窗口或设备。UIElements 与 IMGUI 通过声明依赖复用相同实现。
