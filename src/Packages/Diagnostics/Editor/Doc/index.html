Diagnostics

Use the Profiler for CPU and GPU frames, Memory Profiler for live engine-object snapshots and reference paths, and Remote Player Profiler for an authenticated desktop Player connection.

Remote Player

Game.exe --diagnostics-port 57891 --diagnostics-token a-long-random-token

The host defaults to 127.0.0.1. A non-loopback bind requires a token of at least 16 characters. Samples contain process CPU, managed/private/working-set memory, engine-object count, profiler events and counters, and GPU frame time.

Memory and timing limits

Heap captures describe live BObject instances, shallow estimates and serialized field/list/map references; they are not arbitrary CLR retention graphs. Vulkan timing waits for a queue fence while timing is requested. OpenGL uses asynchronous timer queries.
