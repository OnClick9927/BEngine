BEngine Audio

用于 BEngine 2D 场景的 WAV/MP3/Ogg Vorbis、流式声部、Mixer Group 效果与设备输出。详见 流式音频与混音。

运行、分包与验证

AudioClip.Create/GetData/SetData 管理内存 PCM。AudioSource.Play/PlayDelayed/PlayOneShot/Pause/UnPause/Stop 管理播放，time/timeSamples 查询游标。mute 只将输出增益变为零，仍推进播放位置；Pause 冻结主声部和 OneShot。isPlaying 包含仍存活的 OneShot。

快速开始

  1. 导入 PCM WAV，在 Inspector 核对采样率、通道和时长；通过包的资源加载路径引用 Clip，避免硬编码主机绝对路径。
  2. 在场景放置 AudioListener 与 AudioSource，给 source.clip 赋值；启用 playOnAwake 或从 Start 调用 Play。
  3. 用两段短音调用 PlayOneShot，分别测试 Pause、UnPause、mute、panStereo 和 Stop；循环背景音与一次性提示音使用独立 Source。

组件与 API

AudioClip, AudioSource, AudioListener, AudioOutput, IAudioOutput

source.clip = clip;
source.loop = true;
source.Play();
source.PlayOneShot(click, Fix64.Half);
source.mute = true;

扩展与平台接口

运行时使用 Fix64 和主线程 BTask；通过平台服务读写资源，不直接创建主机文件或网络连接。编辑器代码放在 Editor 装配，停止场景时取消请求并解除订阅。

资源分包与更新

AssetImporter.assetBundleName/assetBundleVariant 指定资源组；BuildPipeline.BuildAssetBundles 接受导入设置或 AssetBundleBuild[]。跨包引用记录为目录依赖。RequiredBundleNames 控制首次安装，IAssetBundleDownloadManager 下载可选组和依赖。已安装可选包参与之后的版本更新。

行为边界

提供 WAV/MP3/Ogg Vorbis、独立流式声部、后台解码和总线 DSP 效果。AudioClip.Create(stream:true) 需要 PCM 回调。设备平台和跳转成本见流式音频与混音文档。PCM 样本以 float 在音频输出边界混合，播放时间和参数使用 Fix64；音频硬件时钟不作为游戏逻辑时钟。

排查与验证

  • 无声：检查 AudioListener.pause/volume、Source.mute/volume、组件 active 状态及平台 IAudioOutput 是否为空输出。
  • 暂停后提示音仍响：检查是否用了不同 Source；同一 Source 的 Pause 应暂停所有声部。
  • 长期静音后恢复从旧位置播放：记录 timeSamples；mute 应持续推进，Pause 才保持位置。
  • 播放后静音若干帧，确认输出为零而 timeSamples 增加。
  • 仅播放 OneShot 时检查 isPlaying=true，Pause 后为 false，UnPause 后继续，Stop 清理所有声部。
  • 用假的 IAudioOutput 记录样本长度与饱和范围，再在目标平台听测左右声道。

Package Manager 导入示例：AudioGettingStarted、OneShotMixer。在 Project 打开场景，检查 Hierarchy/Inspector，比较 Scene 与 Game，Play 后查看 Console，Stop 后再次运行。

本包增加配置、运行时、验证三份 Skills。详细说明见 运行与扩展指南。

快速开始

  1. 在 Window > General > Package Manager 启用 Audio，导入 Audio Getting Started。
  2. 从 Project 打开 Assets/Examples/AudioGettingStarted/res/Audio.scene.yaml。
  3. 选择 Music Source，在 Inspector 检查 Clip、Loop、Volume、Pitch、Pan 和 Play On Awake。
  4. 打开 Scene、Game、Console 后 Play。Space 暂停，方向键调节音量/声像，R 重新播放。

组件介绍

类型职责关键字段
AudioClip保存完整 PCM 或流式来源，是可被 Resources/AssetBundle 加载的 BAsset。samples、channels、frequency、length、loadState
AudioSource播放 Clip 和一次性音效；按优先级进入 2D 软件混音。clip、volume、pitch、panStereo、loop、mute、priority
AudioListener场景监听器标记与全局音量/暂停入口。AudioListener.volume、AudioListener.pause
AudioImporter将 WAV/MP3/Ogg Vorbis 及加载策略转换为 Artifact/AudioClip。loadType、forceToMono、normalize、loadInBackground、preloadAudioData

BEngine 是 2D 引擎。AudioSource 不读取 Transform 距离，不提供 3D spatial blend、doppler、reverb zone 或 3D 环绕定位。

API

创建和读写 Clip

var clip = AudioClip.Create("Tone", 44100, 2, 44100);
clip.SetData(interleavedPcm, 0);
var copy = new float[interleavedPcm.Length];
clip.GetData(copy, 0);

播放控制

var source = GetComponent<AudioSource>();
source.volume = Fix64.Parse("0.8");
source.panStereo = Fix64.Parse("-0.2");
source.Play();
source.PlayOneShot(clickClip, Fix64.Half);

PlayDelayed 接受确定性 Fix64 秒数；time、timeSamples 可定位； Pause/UnPause 保留游标，Stop 清除游标和 one-shot。

编辑器工作流

  1. 将 WAV 拖入 Project。Importer 校验 RIFF/WAVE、fmt 和 data 块并生成 AudioClip。
  2. 在 Inspector 修改导入设置后重新导入；Force To Mono 会合并声道，Normalize 提升峰值。
  3. 从 Project 将 Clip 拖到 Audio Clip ObjectField；类型不匹配时光标明确显示拒绝。
  4. 字段右侧选择按钮打开 Assets/Scene 双页签 TreeView，可搜索且不显示 Assets 根节点。
  5. 修改 Source 使用 Undo；Play 中只改变运行镜像，Stop 后恢复编辑态数据。

如何扩展

平台输出实现 IAudioOutput 并用 AudioOutput.current 安装。提交的是交错 float PCM； 实现需要自行维护设备缓冲，避免在帧热路径分配，并在 Dispose 中释放原生资源。

新增编码格式时，在 Runtime 注册 RuntimeAssetCodecRegistry，在 Editor 注册对应 AssetImporter 和图标。包卸载必须注销静态注册；Inspector 修改依次调用 Undo、赋值、 EditorUtility.SetDirty。

排错

没有声音检查 OpenAL、Listener.pause、Source.mute/volume、Clip 引用和 Play 状态。
导入失败支持 PCM/Float WAV、MP3 和 Ogg Vorbis；在 Console 查看具体格式/解码错误。
播放太快/太慢检查 Clip 采样率与 Source pitch；输出端会按设备采样率重采样。
Stop 后参数恢复这是编辑态/运行态隔离，属于预期行为。
