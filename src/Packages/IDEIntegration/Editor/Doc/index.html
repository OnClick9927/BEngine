IDE Integration

Visual Studio / VS Code 工程同步、C# 代码提示和本机编辑器一键附加。此包只在 Editor 中运行。

开始使用

  1. 在 Package Manager 启用 IDE Integration。
  2. 安装 Hub 同级 Plugin 文件夹中的对应 VSIX。VS Code 还需要官方 C# 扩展。
  3. 打开 BEngine 工程文件夹或根目录的 BEngine.Project.sln，运行 IDE 的 Attach to BEngine 命令。

编辑器的 Tools / IDE / Sync Solution 同步方案，Open Solution 打开方案。双击 C# 文件和 Console 源码位置会按 External Script Editor 偏好打开完整工程。

工程与调试

方案从引擎实际 asmdef 图生成，保留 Runtime / Editor 边界、项目依赖、启用包引用和编译宏。生成项目与构建缓存位于 Library/IDE，不会替代引擎的编译与加载流程。

Editor 发布本项目真实进程的 PID 和启动时间，插件使用本机 .NET 调试器附加。没有额外调试服务器或用户目录全局缓存。原始源码的路径、行号及校验和与 portable PDB 对齐，保留 LoopGuard 和正常的断点源码一致性检查。
