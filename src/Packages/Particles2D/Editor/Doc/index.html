Particles2D

Enable com.bengine.particles2d and add Effects / Particle System 2D. Animation supplies the shared curves, Physics2D supplies collision queries, and Pooling supplies bounded trail reuse.

Emission and lifetime

Use rate emission or Bursts with time, count, repeats and probability. Looping systems repeat the Burst schedule each duration. Size, velocity, angular speed and trail width use curves; color uses gradient keys. Lifetime keys range from 0 to 1. Inspector edits and nested keys support Undo and scene saving.

Sub-emitters and collision

Reference a system in the same scene and choose Birth, Death or Collision, count, color and velocity inheritance. Disable playOnAwake for systems used only by a parent. Cycles are rejected. Add the included Effects / Particle Physics 2D Collision provider for swept collider queries, masks and trigger filtering; enable collision on the particle system and configure bounce, damping and lifetime loss. No separate collision package is required.

The provider sweeps a circle (or a ray for zero radius) along each particle step. Its normal points out of the hit surface. Edit-mode preview queries authored colliders without advancing rigid bodies, then restores the previous physics world. Particles respond to colliders without applying rigid-body forces.

Trails and playback

Trails can remain after particle death, with bounded samples and independent lifetime. Pause freezes simulation. Play resumes. Stop(false) drains existing particles; Stop() clears particles and trails. Prewarm applies to looping playOnAwake systems.

Preview

Enable Edit Mode Preview and scrub Time (up to 3600 seconds). Sub-emitters and authored scene collision participate. A fixed random seed allows repeatable sampling. Save, serialized edits, Inspector close and Play entry clear preview state. See the package Readme for behavior and validation scope.
