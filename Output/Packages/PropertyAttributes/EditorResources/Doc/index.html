Inspector 属性扩展

该包为 SerializedProperty 和 GPU IMGUI Inspector 提供声明式标签、条件显示、验证、数值约束、路径字段、下拉选项、进度显示和内联动作。

常用属性

用途属性
结构与说明Title、LabelText、InfoBox、Indent
条件ShowIf、HideIf、EnableIf、DisableIf
验证Required、ValidateInput、ReadOnly
数值Clamp、MinValue、MaxValue、MinMax、ProgressBar
输入Dropdown、Password、FilePath、FolderPath、AssetPath
动作InlineButton

组合示例

[Title("Identity")]
[LabelText("Display Name")]
[Required]
[ValidateInput(nameof(IsNameValid), "Invalid name", ValidationMessageType.Error)]
public string displayName = string.Empty;

[ShowIf(nameof(showAdvanced))]
[EnableIf(nameof(CanEditSpeed))]
[Range(0, 20)]
[Clamp(1, 12)]
public Fix64 speed;

[Dropdown(nameof(GetProfiles), true)]
public string profile = string.Empty;

[InlineButton(nameof(ResetHealth), "Reset")]
[ProgressBar(0, 100, "Health")]
public Fix64 health;

动态 Dropdown provider 必须是实例字段、属性或零参非 void 方法，值实现 IEnumerable。Validator 支持 bool M() 或 bool M(T value)；InlineButton 支持实例 void M() 或 void M(T value)。

自定义 Drawer

运行时定义继承 PropertyAttribute 的属性；编辑器程序集用 CustomPropertyDrawer 注册 PropertyDrawer，并在不支持的 SerializedPropertyType 上回退到默认字段。

Drawer 代码必须放在示例或包的 Editor 程序集中，运行时组件和属性定义放在 Runtime 程序集中。

Examples
