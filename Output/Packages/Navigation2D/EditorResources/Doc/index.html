Navigation2D

com.bengine.navigation2d 在 X/Y 平面提供确定性占用网格烘焙、A* 路径、Agent、Obstacle、Link 与 Modifier，并依赖 Physics2D 收集碰撞体。

构建导航

  1. 添加 NavigationSurface2D 并设置单元尺寸与收集范围。
  2. 从 Physics2D Collider 和 NavigationObstacle2D 烘焙可行走网格。
  3. 使用 NavigationAgent2D 设置目标；Link 连接离散区域，Modifier 调整可行走性和代价。

查询

var path = new NavigationPath2D();
Navigation2D.CalculatePath(start, target, layerMask, path);

算法阻止对角线穿越被封锁的拐角，并以固定点和稳定 tie-break 保证可重复结果。
