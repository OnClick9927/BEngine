Tiled Map

com.bengine.tiledmap 提供稀疏 2D Tilemap、Atlas Palette、运行时修改 API、视锥裁剪和合批渲染。

编辑流程

  1. 使用 Assets/Create/2D/Tile Palette 创建 .tilepalette.yaml。
  2. 在 Window/2D/Tile Palette 设置 PNG、行列数并执行 Slice Atlas；也可填写 Core .atlas.yaml 并执行 Import Texture Atlas。
  3. 使用 GameObject/2D Object/Tilemap 创建对象，选择 Palette 后绘制。

运行时 API

var map = GetComponent<Tilemap>();
map.SetTile(new TileCoordinate(4, 2), 7);
map.BoxFill(new TileCoordinate(0, 0), new TileCoordinate(3, 1), 2);
var cell = map.WorldToCell(worldPosition);

单元格数据按坐标确定性排序后保存在场景 YAML 中。Tile ID 0 表示空单元格。

渲染

TilemapRenderer 参与统一的 Layer、Order、Hierarchy、Transparency 排序。Material、Shader、Atlas 三项相同且排序后相邻的瓦片会合批。Atlas 使用归一化 UV，支持水平/垂直翻转和 90/180 度组合旋转。
