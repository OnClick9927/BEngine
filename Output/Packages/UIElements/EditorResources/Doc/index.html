BEngine UIElementscom.bengine.ui-elements

保留模式 UI

UIElements 包提供 VisualElement 树、UXML、USS、布局、控件、UIDocument 与 GPU 渲染，并提供 UI Builder 和 HTML/CSS 转换工具。核心编辑器不反向依赖该可选包。

运行时工作流

  1. 通过 Assets/Create/UI Toolkit 创建 UI Document 和 Style Sheet。
  2. 为场景对象添加 UIDocument，设置 UXML 路径和 PanelSettings。
  3. 在 OnEnable 后通过名称查询元素并注册回调。
  4. 使用 USS 配置 flex、尺寸、字体、边框、颜色、margin 和 padding。
var root = document.rootVisualElement;
var status = root.Q<Label>("Status");
var progress = root.Q<ProgressBar>("Progress");
root.Q<Button>("Increment").clicked += OnIncrement;

控件与渲染

输入

Button、Toggle、TextField、IntegerField、FloatField、Slider、DropdownField、ColorField。

数据与集合

Label、Image、ProgressBar、ListView、TreeView、Foldout 与 ScrollView。

工具栏

Toolbar、ToolbarButton、ToolbarMenu、ToolbarSearchField 和 Spacer。

渲染链

布局后由 UIRenderListBuilder 生成命令，再由 UIElementsRenderer 解析纹理和文字资源。

编辑器工具

Window/UI Builder 编辑 UXML/USS；Tools/UIElements/HTML Converter 可把 HTML/CSS 转换为 UXML、USS、绑定脚本和报告。选择 HTML 资源后也可从 Assets 菜单转换。

Examples

Runtime HUD 展示 UIDocument、UXML、USS、按钮、进度条和 TreeView；Controls Gallery 展示常用控件、事件与运行时数据绑定。在 Package Manager 的 Examples 页签导入。
