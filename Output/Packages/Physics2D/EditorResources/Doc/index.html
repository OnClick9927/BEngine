Physics2D

com.bengine.physics2d 提供固定点 2D 刚体、碰撞体、查询与碰撞/触发回调。位置和速度使用 Vector2，旋转使用标量角度。

建立刚体

  1. 添加 Box、Circle、Capsule 或 Polygon Collider2D。
  2. 动态对象添加 Rigidbody2D，设置质量、阻尼、重力和约束。
  3. 使用 PhysicsMaterial2D 设置摩擦和弹性。

查询

if (Physics2D.Raycast(origin, direction, out var hit, distance, layerMask))
    Debug.Log(hit.collider.gameObject.name);

还可使用 OverlapCircle、OverlapBox 与 CircleCast。Layer mask 使用引擎的 power-of-two ulong 层。
