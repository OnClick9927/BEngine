CORE MANUAL

BEngine Core

Core 提供 Scene、GameObject、Component、序列化、渲染基础和 Unity 风格编辑器扩展 API。运行 Output/BEngine.bat 后，可从 Package Manager 按需启用功能包。

世界只包含 X/Y 坐标与一个旋转角；Sprite、粒子、Tilemap 与 UI 使用统一的 2D 排序和合批队列。

业务资源只放入 Assets。包由 Package Manager 管理，包文档、技能和示例分别位于包自身的 EditorResources/Doc、EditorResources/Skills 和 EditorResources/Examples。

运行时对象

场景与层级

Scene 管理根对象；Transform 维护父子关系。加载模式支持 Single 和 Additive，持久对象通过 DontDestroyOnLoad 保留。

生命周期

Awake → OnEnable → Start → Update → LateUpdate → OnDisable → OnDestroy。固定步长逻辑在 FixedUpdate 执行。

Scene 与 Game

Scene 视图使用唯一的 2D 编辑器相机；Game 视图使用场景中的 Camera2D，并可按渲染优先级叠加多个相机。

单线程运行

SceneRuntime 在同一线程依次执行脚本、协程、包运行系统与渲染；编辑器扫描、编译、哈希和文件 IO 可在后台执行。

托管场景与依赖注入

Scene 直接拥有 GameObject，GameObject 直接拥有 Component；统一通过托管查询访问场景组件。

var player = scene.CreateGameObject("Player");
player.AddComponent<PlayerController>();
foreach (var controller in scene.QueryComponents<PlayerController>())
    controller.ResetState();

有状态服务通过 Microsoft.Extensions.DependencyInjection 注册。项目、Scene 和窗口分别拥有明确 scope；扩展包实现 IEngineServiceModule 添加服务。

编辑器扩展

常用入口

MenuItem、EditorWindow、CustomEditor、CustomPropertyDrawer、SettingsProvider。

编辑器生命周期

InitializeOnLoad、DidReloadScripts、CompilationPipeline、AssemblyReloadEvents 和资源处理器回调。

包的菜单项应归入与功能相关的标准菜单；示例扩展命令统一放在 Tools 下。一个扩展报错会被功能边界隔离，不应阻断其他窗口或菜单。

Texture Atlas

从 Assets/Create/2D/Texture Atlas 创建 .atlas.yaml，在 Window/2D/Texture Atlas 添加 PNG 来源并 Build。打包器会确定性生成 2 的整数次方 PNG，Padding 和 Extrude 用于隔离相邻区域。

renderer.atlas = "Assets/Art/Characters.atlas.yaml";
renderer.sprite = "hero_idle";

SpriteRenderer 与 ParticleSystem2D 会读取区域 UV 和 pivot。共享 Material、Shader、Atlas 且排序后相邻的项目合并为一次绘制；TiledMap 的 Tile Palette 也可直接导入 Texture Atlas 区域。

资源与包

AssetDatabase 负责 GUID、meta、导入和打开资源；Resources 是运行时兼容入口。AssetBundle 使用确定性构建、内容哈希缓存、依赖清单、原子激活和回滚实现资源热更。

.bpackage 用于把示例或资源集合导入工程；包示例默认不进入新工程，应由使用者在 Package Manager 的 Examples 页签主动 Import 或 Reimport。
